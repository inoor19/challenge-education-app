STEP 1: INSTALL ANDROID SDK (20-30 min)

  ┌─────────────────────────────────────────────────────────────────────────┐
  │ 1. Go to: https://developer.android.com/studio                          │
  │ 2. Download & Run installer                                              │

  ┌─────────────────────────────────────────────────────────────────────────┐
  │ Run this PowerShell command:                                             │
  │                                                                           │
  │ [Environment]::SetEnvironmentVariable(                                   │
  │   "ANDROID_HOME",                                                        │
  │   "C:\path\to\your\android\sdk",                                         │

🐛 IF SOMETHING GOES WRONG
═══════════════════════════════════════════════════════════════════════════════

"No Android SDK found"
  → Follow ANDROID_SDK_SETUP.md → Option 1 (Android Studio)

"Keystore not found"
  → Check: mobile/android/upload-keystore.jks exists? (should be ~6 KB)

"Build fails with error"
  → Run: flutter doctor -v
  → Shows detailed diagnostic info
  → Copy-paste error into search or check GOOGLE_PLAY_UPLOAD_GUIDE.md

"Upload rejected"
  → Check console message (usually specific reason)
  → Common: Missing privacy policy, wrong icon size, incomplete listing
  → Fix issue → Increment version code → Rebuild → Re-upload
