# Google Play Screenshots Guide

## Screenshot Requirements

| Requirement | Details |
|------------|---------|
| **Format** | PNG or JPEG |
| **Dimensions** | 1080 x 1920 pixels (9:16 aspect ratio) |
| **Minimum** | 2 screenshots |
| **Recommended** | 5-8 screenshots |
| **Max file size** | 8 MB per image |
| **Language** | Should match app language (Arabic) |

## How to Take Screenshots

### Option 1: Using Android Emulator (Easiest)

1. Install Android Studio
2. Open your Flutter app in emulator
3. Run: `flutter run`
4. In emulator, press Ctrl+S (Windows) or Cmd+S (Mac) to take screenshot
5. Screenshots save to: `~/Pictures/Emulator Screenshots/`

### Option 2: Using Real Device

1. Connect Android phone via USB
2. Enable Developer Mode (tap Build Number 7 times in Settings)
3. Enable USB Debugging
4. Run: `flutter run`
5. Use device's built-in screenshot (Volume Down + Power)
6. Transfer to computer

### Option 3: Using Chrome DevTools

1. Run: `flutter run -d chrome`
2. Open app in browser
3. Right-click → Inspect → Device Emulation
4. Set to mobile view (1080 x 1920)
5. Screenshot the browser window

## Text Overlay Guide

**Using Photoshop/GIMP:**

1. Open screenshot
2. Add text layer
3. Font: Tajawal (Arabic font) or similar
4. Size: 48-72pt for headers, 32-48pt for descriptions
5. Color: White with shadow for readability
6. Position: Top or bottom 20% of screen

**Using Online Tools:**
- Canva.com - Drag & drop text on images
- Pixlr.com - Free online photo editor
- Photopea.com - Free Photoshop alternative

## Color & Design Guidelines

### Colors
- **Primary**: Gold (#D4AF37)
- **Secondary**: Dark Blue (#1a237e)
- **Background**: Light gray (#f5f5f5)
- **Text**: Dark gray (#333333)
- **Accent**: Green (for success/correct answers)

### Typography
- **Headers**: Tajawal Bold, 48pt
- **Body**: Tajawal Regular, 32pt
- **Captions**: Tajawal Light, 24pt

### Layout
- Top text: 10-15% from top
- Center text: 40-50% from top
- Bottom text: 10-15% from bottom
- Margins: 40-60px from edges

## Quick Screenshot Taker Script

Save as `take_screenshots.sh`:

```bash
#!/bin/bash

# Start Flutter app
flutter run &
sleep 5

# Take screenshots (adjust emulator name as needed)
emulator -avd Pixel_4_API_30 &
sleep 10

# Take multiple screenshots
for i in {1..8}; do
    adb shell screencap -p /sdcard/screenshot_$i.png
    adb pull /sdcard/screenshot_$i.png ./screenshots/
    sleep 2
done

echo "Screenshots saved in ./screenshots/"
```

Run with: `bash take_screenshots.sh`

## Upload to Google Play

1. Go to: Google Play Console → Your App → Store Listing
2. Scroll to: "Screenshots" section
3. Click: "Add Screenshot"
4. Select all 5-8 screenshots
5. They auto-arrange in order
6. Preview on different devices
7. Save and continue

## Pro Tips

✅ **Do:**
- Show actual app UI
- Include Arabic text
- Display key features
- Show progression/success
- Use consistent branding
- Include device bezels (makes it look real)

❌ **Don't:**
- Use placeholder content
- Show personal information
- Include sensitive data
- Use low-quality images
- Show error messages
- Add too much text
