# How to Use Screenshot Mockups

## 📱 Two Options for Screenshots

### Option 1: Use the HTML Mockups (FASTEST - 5 minutes)

**File:** `screenshots-mockup.html`

**Steps:**
1. Open `screenshots-mockup.html` in your browser (just double-click it)
2. It shows all 8 screenshots in responsive design
3. For each screenshot:
   - Click on it to view full size
   - Right-click → "Save image as" → Save as PNG
   - Or press `Print Screen` / `Ctrl+Print Screen`
   - Use Snipping Tool to capture the image

**Pros:**
- ✅ Takes 5 minutes
- ✅ Already formatted correctly
- ✅ Ready to upload immediately
- ✅ Professional design

**Cons:**
- ❌ Not actual app screenshots
- ❌ Mockup style

---

### Option 2: Take Real Screenshots from App (45 minutes)

**Steps:**
1. Install Android Emulator in Android Studio
2. Run Flutter app: `flutter run`
3. Navigate to each screen
4. Take screenshots (1080x1920 pixels)
5. Crop and edit if needed

**Pros:**
- ✅ Real app screenshots
- ✅ Show actual UI/UX
- ✅ Better for app store
- ✅ More professional

**Cons:**
- ⏱️ Takes 45-60 minutes
- 🛠️ Requires Android Studio setup
- 🔧 More technical

## 📸 How to Get Screenshots from HTML Mockup

### Method 1: Browser Screenshot (Easiest)

1. Open `screenshots-mockup.html` in Chrome/Firefox
2. Press F12 (Developer Tools)
3. Press Ctrl+Shift+M (Mobile View)
4. Set size to: **Width: 1080, Height: 1920**
5. Right-click → Inspect
6. Click the device icon in DevTools
7. In the left panel, take screenshot:
   - Menu (⋮) → Capture screenshot
   - Saves to Downloads

### Method 2: Print to PDF + Convert

1. Open `screenshots-mockup.html`
2. Right-click → Print
3. Change destination to "Save as PDF"
4. Print
5. Open PDF in image editor
6. Export as PNG

### Method 3: Snipping Tool

1. Open `screenshots-mockup.html`
2. Open Windows Snipping Tool (Win+Shift+S)
3. Drag to select each screenshot
4. Save as PNG

## 💡 Pro Tips

1. **Create screenshots folder first:**
   ```bash
   mkdir screenshots
   ```

2. **Keep originals intact:**
   - Don't overwrite files
   - Keep backups

3. **Resize if needed:**
   - If screenshots are wrong size
   - Use: https://pixlr.com/
   - Or: https://www.canva.com/

4. **Add text overlays (optional):**
   - Download GIMP (free): https://www.gimp.org/
   - Or use Canva (free): https://www.canva.com/
